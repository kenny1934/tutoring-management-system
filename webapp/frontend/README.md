# CSM frontend

This is the Next.js app that tutors and admins use every day, along with the public summer and regular intake pages that parents see. The backend it talks to lives in `../backend`.

If you're changing how a staff page looks, read `DESIGN.md` first. It explains the colour tokens, the shared controls in `components/controls` and the few places that keep their own character, such as lesson mode and the public pages.

The commands you'll need most, such as running the tests, signing in locally without Google and taking screenshots of real screens, are listed under Common Commands in the `CLAUDE.md` at the root of the repository. The changelog and the release steps are described there too.

The two design documents from the first version of the app, the component brainstorm and the dark-mode audit, have moved to `docs/archived/design/`. They describe the earlier look and are kept only as history.
